# WANDERLUST TRAVEL WEBSITE

A modern and responsive travel website designed to showcase destinations, travel packages, special offers, and travel experiences through a clean and attractive user interface.

## About

**Wanderlust Travel Website** is a frontend web development project created using **HTML and CSS**.

The website provides a travel-focused interface where users can explore popular destinations, view travel packages, read customer reviews, learn about the travel service, and find booking information.

## Travel Packages

The website showcases different travel packages with information such as:

* Destination
* Duration
* Accommodation
* Airport transfer
* Meals
* Tours and activities
* Package price

## Why Choose Us

The website highlights four main services:

* Expert Planning
* Best Price
* Trusted Service
* 24/7 Support

## Website Sections

### Home

The homepage introduces Wanderlust Travel with a large hero section, navigation menu, travel message, and search area.

### Destinations

Displays popular destinations with images and information to help users explore different places.

### About

Provides information about the travel service along with travel-related statistics.

### Packages

Displays travel packages with their destinations, duration, included services, and prices.

### Why Choose Us

Highlights the main reasons customers can choose the travel service, including planning, pricing, trust, and support.

### Reviews

Displays customer reviews to provide feedback and travel experiences.

### Contact / Booking

Provides a section where users can find booking and contact information.

### Footer

Contains quick navigation links, popular destinations, social links, and copyright information.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website.

No additional installation is required.
