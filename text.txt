1. MULTI-PAGE NAVIGATION
   ==================================================

Your navbar should now contain links to different pages.

Example structure:

Home
Destinations
Packages
Dashboard
Contact

Instead of using:

<a href="#destinations">

Use:

<a href="destinations.html">

For the dashboard:

<a href="dashboard.html">

For contact:

<a href="contact.html">

IMPORTANT:

A link like:

#destinations

moves to a section on the same page.

A link like:

destinations.html

opens another HTML page.

22. CSS VARIABLES
=================

Create a central color system.

Example:

:root {

```
--primary: #0F766E;

--secondary: #14B8A6;

--accent: #F59E0B;

--dark: #0F172A;

--light: #F8FAFC;

--white: #FFFFFF;
```

}

Use these variables throughout the project.

Do not repeatedly write the same color everywhere if you can use a variable.
